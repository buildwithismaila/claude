# Start Here

This companion is built around one thing: the **50 PGD examination questions** for ELE 717 Solid State Electronics. Every question has a full model answer written the way you should write it in the exam, with the terms it uses defined, the marking points listed, the usual mistakes pointed out, and a variant question to test yourself.

It is separate from the week-by-week course. Use the weekly course to learn a topic properly; use this companion to turn that understanding into marks.

## How to use it: three passes

1. **Understand.** Read the model answer for a question, slowly, with the key terms. If something is still unclear, open the week named under "Full notes".
2. **Write.** Cover the model answer. Write your own answer on paper, under exam conditions (about 1½ minutes per mark, or 15–20 minutes for a long question). Then mark it against the **marking checklist**. Every missing point is a mark you would have lost.
3. **Recall.** In the last days, use the **Last-minute flashcards** page: one line per question. Then sit the **practice papers**, timed.

Tick each page as done with the button at the bottom; your progress is remembered in this browser.

## Command words: what each one asks for

| Command word | What to do | How much to write |
|---|---|---|
| **Define / What is** | Give the precise meaning in one or two sentences, with the symbol and unit if there is one. Add an example. | Short, exact |
| **State** | Write the law or equation, with its symbols defined. No proof needed. | Short |
| **Explain** | Say *why* or *how*: give the mechanism, step by step, with a diagram if it helps. | Medium to long |
| **Describe** | Say *what happens*, in order (stages, procedure). | Medium |
| **Distinguish / Differentiate** | Give the features of each, side by side. Finish with a table. | Medium |
| **Compare** | Like distinguish, but cover similarities as well as differences, under the headings the question names. Finish with a table. | Medium to long |
| **Derive** | Start from stated assumptions and known laws; number each step; end with the boxed result. | Long |
| **Calculate / Determine** | Show the formula, the substitution with units, and the answer with its unit. | Short |

## Exam technique that earns marks

- **Define before you use.** Start long answers with one-line definitions of the key terms. Markers give marks for them, and it organises your answer.
- **Every equation needs its symbols.** Write "where n = electron concentration (m⁻³), …" under each equation. An equation with undefined symbols often scores half.
- **Draw.** Band diagrams, profiles and I-V curves earn marks quickly. Label the axes, the levels (E_c, E_v, E_F) and the key quantities (qV_bi, W, Φ_B).
- **Units, always: use SI.** Work in metres throughout (m⁻³, m²/V·s, V/m, F/m); the answer then comes out in A/m², m, V. Energies stay in eV. If a question gives data in centimetre units (as Q19, Q29, Q34 and Q38 do), convert them in your **Given** line first, e.g. 5×10¹⁶ cm⁻³ = 5×10²² m⁻³. The conversion table is on the Formula and constants sheet.
- **Derivations: assumptions first.** List the assumptions, number the steps, put a box round the result. Even if you get stuck, the assumptions and the start earn marks.
- **Comparisons: end with a table.** It is quick for the marker to check and shows you covered every heading.
- **Say what the number means.** One sentence after a calculation ("the field is low enough for v = μE to hold") shows understanding.
