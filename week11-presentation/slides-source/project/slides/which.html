Which kind of contact forms depends on which Fermi level is higher before contact, that is, on the two work functions. On n-type silicon, a metal with the larger work function takes electrons from the semiconductor: a depletion layer and a Schottky barrier. A metal with the smaller work function gives electrons to the semiconductor: an accumulation layer and an ohmic contact. On p-type silicon the conditions are reversed, because the majority carriers are holes. This is the ideal picture; in practice heavy doping is used to make ohmic contacts, as we will see.
